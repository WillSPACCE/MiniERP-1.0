## 1. Objetivo visual

Sistema ERP moderno, profissional, limpo, rápido e fácil de usar.

Referência de experiência:

- sistemas ERP SaaS modernos
- Bling como referência de facilidade de uso (apenas como inspiração de UX)

**IMPORTANTE:** Não copiar identidade visual, código, logotipo ou telas do Bling ou de
qualquer outro sistema. Criar identidade própria do Mini ERP Web.

## 2. Princípios de UX

Priorizar sempre:

- simplicidade
- clareza
- rapidez
- poucos cliques para completar uma ação
- informações importantes em destaque
- ações fáceis de encontrar
- feedback imediato ao usuário
- consistência entre todas as telas

## Regra visual

Antes de criar uma nova tela:

1. Consultar este arquivo (visual-memory.md).
2. Reutilizar componentes existentes.
3. Não criar estilos diferentes sem necessidade.
4. Manter espaçamentos consistentes.
5. Manter tipografia consistente.
6. Manter cores consistentes.
7. Manter comportamento consistente.

Se um novo componente visual for criado, adicioná-lo à seção 18 deste arquivo.
