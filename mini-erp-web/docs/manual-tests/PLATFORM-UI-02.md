# Teste manual PLATFORM-UI-02

1. Acessar o login do Control-Plane e confirmar que o card é compacto e alinhado com a identidade visual do painel.
2. Validar que os botões mantêm altura compacta e que o foco visual permanece visível.
3. Confirmar que os inputs e selects apresentam altura menor, padding consistente e boa legibilidade.
4. Verificar dashboards, listas de empresas e páginas de detalhe com maior densidade visual sem perder legibilidade.
5. Abrir a tela de certificado e confirmar que o status e o formulário ficam compactos, claros e profissionais.
6. Validar responsividade em desktop, tablet e mobile.
7. Confirmar que as mensagens de sucesso, alerta e erro continuam legíveis e com tom suave.
8. Rodar os testes estáticos de regressão visual para verificar as classes e tokens esperados.
